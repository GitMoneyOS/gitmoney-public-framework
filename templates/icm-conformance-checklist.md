# ICM Conformance Checklist

Use this checklist to audit a pull request before owner approval:

## 1. Identity & Authority
- [ ] Bounded task stated in plain English.
- [ ] Accountable human owner named.
- [ ] Agent has not attempted to self-approve.

## 2. Context & Data Boundaries
- [ ] Only approved input files were utilized.
- [ ] Zero secrets, private tokens, or client data exposed.

## 3. Quality & Verification
- [ ] All verification checks executed and documented.
- [ ] Zero em dashes and zero banned AI buzzwords.
- [ ] Clean rollback path documented.

## Conformance Verdict
```text
[ ] CONFORMANT (Ready for merge)
[ ] NON_CONFORMANT (Revisions required)
```
