# Agent Platform Routing

## Chain Of Command

1. Source memory or issue.
2. CEO node and agent card when owner context or final authority matters.
3. Swarm executive nodes and agent cards (CMO, CTO, COO) based on domain context.
4. Diamond Hash when voice, identity, ontology, myth, or signal fidelity matters.
5. GitMoney OS Bridge when GitMoneyOS, AI Office, GitHub promotion, or reusable doctrine matters.
6. Bounded agent brief.
6. Local artifact or branch.
7. Evidence.
8. Human approval.
9. GitHub issue, PR, merge, or explicit handoff.

## Canonical Routing Overlay — 2026-07-16

For cross-functional work, load [[180_Mothership_PKM_Second_Brain_Control_Plane_2026-07-16]] and use:

```text
Hitsuyo owner authority
  -> Mothership C-Suite executive framing
  -> Sovereign Router execution-stack selection
  -> one domain metaskill
  -> smallest specialist, script, harness, connector, or tool
  -> acceptance evidence and GitMoney lifecycle record
```

This overlay supersedes direct card-to-tool routing where the older map conflicts. A platform or
model choice changes execution mechanics, not authority. Graphify supplies bounded retrieval;
Skill Creator governs package quality; Doctor Who governs the Lab technical control room.
