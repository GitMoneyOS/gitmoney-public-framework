# Agent Command Patterns

## Purpose

Provide simple, public command prompts for students and adopters interacting with an AI assistant on the workbench.

## Basic Command Patterns

### 1. Capture and Shape
- "Capture this idea into my inbox note."
- "Summarize this note and suggest relevant tags."

### 2. Route and Brief
- "Turn this note into a bounded agent brief."
- "Review the board and show what is in Doing."

### 3. Prepare Promotion
- "Prepare this note as a promotion candidate."
- "Generate a verification receipt for this deliverable."
