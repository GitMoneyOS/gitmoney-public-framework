# Knowledge to Asset

## Purpose

Outline the public protocol for identifying and promoting reusable business assets from Source Memory.

## The Five-Step Rule

The public framework uses a simple rule:

1. Capture information.
2. Identify reusable value.
3. Prepare a promotion candidate.
4. Require owner approval.
5. Record approved assets in the official record.

## Private Operator Boundary

Advanced scoring, pattern detection, diagnostic heuristics, and automated asset-selection methods are part of the private GitMoney implementation system.
