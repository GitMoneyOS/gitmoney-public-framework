# Anti-Patterns

## Purpose

Identify and explain common Source Memory anti-patterns to avoid.

## Owner

Red Pillar and Hitsuyo Aku, under KnowTheLedge.

The ten ways students stall their vault, and the counter for each. Check this list at every weekly review.

## 1. Setup Paralysis

Tweaking folders, themes, and plugins for days before capturing one real idea.

**Counter:** The 30-minute win in `START_HERE.md` comes before any customization. One real note beats a perfect empty system.

## 2. Folder Overwhelm

Inventing a folder for every topic until filing requires a decision tree.

**Counter:** The lanes are fixed. Ten numbered folders, four utility folders. Links do the organizing that folders cannot.

## 3. Metadata Fatigue

Twenty frontmatter fields, most empty, all guilt.

**Counter:** Six required fields. Anything beyond that must earn its place in a template or get cut.

## 4. Fake Linking

Linking every note to every note because a tutorial said links are the point.

**Counter:** One real contextual link beats ten reflex links. A link must say something a folder cannot.

## 5. Input Hoarding

Clipping fifty articles a week and reading none. The vault becomes a landfill with good lighting.

**Counter:** The weekly review empties the inbox: file it, link it, or archive it. Archiving an unread clip is success, not failure.

## 6. Plugin Bloat

Installing every community plugin with stars.

**Counter:** Version 1 runs on core plugins only. A plugin is added only when a named, recurring task demands it.

## 7. AI Amnesia

Every agent session starts from zero; the agent relearns the vault, repeats old mistakes, and contradicts old decisions.

**Counter:** Read `_agent-context/AGENT_CONTEXT.md` at session start; append `MEMORY_LOG.md` at session end. Decisions live in `80-decisions/` where agents can find them.

## 8. Vibe-Coding Without Blueprint

Asking an agent to build software from a vague feeling.

**Counter:** No AI coding or deployment before a `PROJECT_BLUEPRINT.md` or `SPEC.md` exists. The blueprint is the inexpensive place to be wrong.

## 9. Agent Jobs Without Scope

"Clean up my vault." "Make this better." "Handle my content."

**Counter:** The workbench contract. No brief, no job. A brief without scope and completion criteria is bounced back with questions.

## 10. Promoting Private Memory As Public Record

Pushing raw notes, doctrine, half-thoughts, or client details to GitHub because they look finished.

**Counter:** The promotion rules. Everything is `private` until classified otherwise; promotion requires the asset test plus owner approval plus the public safety check. Private memory leaking into the official record is the primary mistake this architecture prevents.
