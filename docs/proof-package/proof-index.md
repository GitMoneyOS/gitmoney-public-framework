# Proof Index

## Purpose

Make the public proof layer inspectable in one place.

A founder should not have to assemble the case from scattered files like an underpaid archaeologist dusting off someone else's operational skeleton. This index maps the public claim to the evidence, the proof level, the boundary, and the paid implication.

## How to read this

The framework separates four things:

1. **Claim:** what the public material can safely say.
2. **Evidence:** what a reader can inspect.
3. **Open skeleton:** what the public framework deliberately makes reusable.
4. **Private machine:** what remains proprietary implementation, judgment, and client-specific work.

A strong proof layer does not make bigger claims. It makes cleaner claims.

## Safe claims

GitMoney OS Public Framework can safely claim that it demonstrates:

- an open public standard for governed AI-assisted business work;
- a public AI Office control model;
- live GitHub evidence;
- public/private boundary discipline;
- approval packet logic;
- issue, PR, commit, and receipt patterns;
- self-audit and remediation behavior;
- a plain-language way for founders to inspect AI-assisted work.

## Claims to avoid

Do not claim GitMoney OS Public Framework proves:

- legal defensibility;
- financial return;
- security compliance;
- investor readiness;
- acquisition readiness;
- production-grade SaaS readiness;
- validated client outcomes;
- proven 9-figure outcomes;
- full automation;
- universal applicability;
- that private GitMoney OS methods are open source.

Those require separate evidence.

## Paid implication

The public framework gives away the grammar.

The **Identity Forensics Audit** applies judgment to a specific business constraint.

The **Architecture Sprint** handles one bounded architecture question.

**Sovereign Reconstruction** installs the private operating architecture after evidence supports the build.

The skeleton is open. The living machine is paid.
