# Contributing

## Purpose

Keep GitMoney OS changes reviewable, plain-English, and connected to business control.

## Plain-English Job

This guide tells human contributors and AI agents how to propose improvements to the public framework without breaking classification boundaries or publishing unverified material.

## Who This Is For

This file is for developers, technical writers, operators, and agents submitting pull requests or issues to the open-source public framework repository.

## Branch Naming

Use short, descriptive branch names:

- `docs/audit-template`
- `setup/repo-baseline`
- `content/case-file-draft`
- `saas/score-model`

## Pull Request Checklist

*Note: These checkboxes are a template for contributors to follow.*

- [ ] The business change is clear.
- [ ] The owner is named.
- [ ] The evidence is attached or described.
- [ ] No secrets, client private data, or unapproved claims are included.
- [ ] AI-generated work was reviewed by a human owner.
- [ ] All modified Markdown files conform to the Markdown Surface Contract.
- [ ] Zero em dashes are present in public documentation.

## Required Before Submitting

- Explain the business reason.
- Name the owner.
- Attach the verification receipt.
- Confirm that no internal or client data is included.
